# 静态资源说明

## 需要添加的图片资源

请将以下图片放置在 `src/static/` 目录下：

### 顶部横幅区域
1. **header-banner.png** - 顶部完整横幅图片（包含标题、Logo、宣传标语、九江标志等所有内容）

### 功能菜单图标
2. **icon-roster.png** - 人员名单图标（绿色，人员卡片样式）
3. **icon-survey.png** - 问卷调查表图标（蓝色，问卷编辑样式）
4. **icon-report.png** - 报告查询图标（橙色，文档样式）
5. **icon-service.png** - 联系客服图标（粉色，耳机样式）

### 问卷调查页面图标
6. **icon-medical-bag.png** - 医疗包图标（蓝色，用于顶部卡片）
7. **icon-check-green.png** - 绿色勾选图标（用于优势列表）

## 图片尺寸建议

- **header-banner.png**: 建议宽度 750px（全屏宽度），高度根据设计图比例调整
- **功能菜单图标**: 建议尺寸 120x120px（透明背景PNG格式）

## 临时处理

如果暂时没有准备好这些图片，可以：
1. 使用纯色占位图
2. 使用文字替代图标
3. 先注释掉 image 标签，使用文字显示

## 页面预览

完成图片资源添加后，运行以下命令预览页面：

```bash
cd h5
npm run dev:h5
```

页面将在浏览器中打开，可以查看首页效果。
