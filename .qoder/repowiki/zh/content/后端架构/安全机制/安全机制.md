## 安全架构概述

本系统采用Spring Security框架实现全面的安全控制，结合JWT（JSON Web Token）实现无状态认证，通过RBAC（基于角色的访问控制）模型管理用户权限。系统安全架构分为认证、授权、数据过滤和安全防护四个主要部分。

### 数据范围过滤实现

`DataScopeAspect`切面在方法执行前处理`DataScope`注解，根据用户角色和权限动态构建SQL过滤条件。

```mermaid
sequenceDiagram
participant Controller as "控制器方法"
participant Aspect as "DataScopeAspect"
participant User as "当前用户"
participant Role as "用户角色"
participant SQL as "SQL构建"
Controller->>Aspect : 调用带@DataScope注解的方法
Aspect->>User : 获取当前登录用户
alt 用户是管理员
User-->>Aspect : 跳过数据过滤
Aspect->>Controller : 继续执行
else 普通用户
Aspect->>Role : 获取用户所有角色
loop 遍历每个角色
Role->>SQL : 根据角色数据范围类型构建SQL条件
alt DATA_SCOPE_ALL
SQL->>SQL : 不添加过滤条件(所有数据)
else DATA_SCOPE_CUSTOM
SQL->>SQL : 添加自定义部门过滤
else DATA_SCOPE_DEPT
SQL->>SQL : 添加本部门过滤
else DATA_SCOPE_DEPT_AND_CHILD
SQL->>SQL : 添加本部门及子部门过滤
else DATA_SCOPE_SELF
SQL->>SQL : 添加仅本人数据过滤
end
end
Aspect->>Controller : 设置数据范围参数
Controller->>数据库 : 执行带过滤条件的查询
end
```
