# 微信小程序热更新问题解决指南

## 🔍 问题描述
使用 `npm run dev:mp-weixin` 开发微信小程序时，修改代码后开发服务器未能自动重新编译和刷新，必须手动重启才能看到更改效果。

## ✅ 已实施的解决方案

### 1. Vite配置优化（已完成）
已在 `vite.config.js` 中添加以下配置：

```javascript
server: {
  hmr: true,              // 启用热模块替换
  host: '0.0.0.0',        // 监听所有地址
  port: 5173,             // 指定端口
  open: false             // 不自动打开浏览器
}
```

## 🛠️ 微信开发者工具配置

### 方法一：关闭微信开发者工具的热重载（推荐）

**原因**：微信开发者工具自带的 `compileHotReLoad` 功能可能与 Vite 的 HMR 冲突。

**操作步骤**：
1. 打开微信开发者工具
2. 点击右上角 `详情` 按钮
3. 找到 `本地设置` 标签页
4. **取消勾选** `编译时自动刷新` 或 `启用自动编译`
5. **勾选** `不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书`

### 方法二：修改微信开发者工具配置文件

在项目根目录的 `project.config.json` 中添加：

```json
{
  "setting": {
    "compileHotReLoad": false
  }
}
```

## 📝 开发流程规范

### 启动开发服务器
```bash
cd h5
npm run dev:mp-weixin
```

### 导入微信开发者工具
1. 打开微信开发者工具
2. 选择 `导入项目`
3. 项目目录选择：`h5/dist/dev/mp-weixin`
4. AppID 选择：测试号或实际小程序 AppID

### 开发注意事项

#### ✅ 普通文件修改（支持热更新）
- `.vue` 文件中的 `<template>` 修改
- `.vue` 文件中的 `<script>` 修改
- `.vue` 文件中的 `<style>` 修改
- `src/api/` 目录下的 API 文件
- `src/static/` 目录下的静态资源

**操作**：保存文件后，微信开发者工具会自动编译并刷新

#### ❌ 配置文件修改（需要重启服务）
- `src/pages.json` - 页面路由配置
- `src/manifest.json` - 应用配置
- `vite.config.js` - Vite 配置
- `package.json` - 依赖配置

**操作**：
1. 停止开发服务器（Ctrl+C）
2. 重新运行 `npm run dev:mp-weixin`
3. 微信开发者工具会自动重新编译

## 🐛 问题排查清单

### 1. 检查终端日志
观察 `npm run dev:mp-weixin` 的输出，是否有编译错误或警告：
```
✓ built in xxxms
```

### 2. 检查微信开发者工具控制台
- 打开 `调试器` → `Console`
- 查看是否有 JavaScript 错误
- 查看是否有资源加载失败

### 3. 清除缓存
**微信开发者工具**：
- 点击右上角 `清除缓存` → `清除全部缓存`
- 重新编译项目

**终端**：
```bash
# 删除 node_modules 和锁文件（慎用）
rm -rf node_modules package-lock.json
npm install

# 清除 dist 目录
rm -rf dist
npm run dev:mp-weixin
```

### 4. 检查文件路径大小写
Windows 系统不区分大小写，但某些工具会严格区分，确保：
- 文件夹名称使用小写或短横线分隔：`user-info` 而不是 `UserInfo`
- import 路径大小写与实际文件名一致

### 5. 检查端口占用
```bash
# Windows 检查端口占用
netstat -ano | findstr :5173

# 如果端口被占用，杀死进程
taskkill /PID <进程ID> /F
```

### 6. 检查文件监控限制
某些系统对文件监控数量有限制，确保 Vite 能够正常监控文件变化。

## 🚀 优化建议

### 1. 使用 pnpm 替代 npm（可选）
```bash
npm install -g pnpm
pnpm install
pnpm run dev:mp-weixin
```

### 2. 减少监控文件数量
在 `vite.config.js` 中排除不需要监控的目录：
```javascript
server: {
  watch: {
    ignored: ['**/node_modules/**', '**/dist/**']
  }
}
```

### 3. 开启开发者工具的调试模式
- 微信开发者工具 → 设置 → 外观设置 → 开启调试模式
- 可以查看更详细的编译日志

## 💡 常见问题 FAQ

### Q1: 修改代码后没有任何反应？
**A**: 检查终端是否有编译错误，确保文件已保存，微信开发者工具是否导入了正确的目录。

### Q2: 编译成功但页面不刷新？
**A**: 尝试手动点击微信开发者工具的 `编译` 按钮，或关闭工具的热重载功能。

### Q3: 某些文件修改生效，某些不生效？
**A**: 检查是否修改了配置文件（pages.json、manifest.json），这些需要重启服务。

### Q4: 真机调试时热更新失效？
**A**: 真机调试不支持热更新，需要重新点击 `预览` 生成新的二维码。

## 🎯 快速测试

```vue
<template>

    <text>热更新测试 - {{ new Date().toLocaleTimeString() }}</text>
  </view>

```

保存后，观察微信开发者工具是否自动刷新并显示当前时间。
