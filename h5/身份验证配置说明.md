# 身份验证功能配置说明

## 当前状态

✅ **身份验证功能已集成但未启用**

- 默认使用前端格式验证 + 信息提取
- 真实API验证功能已准备好，但处于关闭状态
- 等后端API准备就绪后可随时开启

## 功能说明

### 当前模式（默认）

**前端格式验证模式**
- ✅ 验证姓名格式（2-10个中文字符）
- ✅ 验证身份证号码格式（18位有效格式）
- ✅ 自动提取年龄、性别
- ❌ 不验证姓名和身份证号是否真实匹配

### 可选模式

**真实API验证模式**
- ✅ 所有前端格式验证功能
- ✅ **调用第三方API验证姓名和身份证号是否真实匹配**
- ✅ 智能降级：API失败时自动提示用户选择

## 如何启用真实API验证

### 步骤1：准备后端API

参考 `h5/src/api/README.md` 选择并集成实名认证服务：
- 阿里云实人认证（推荐）
- 腾讯云人脸核身
- 聚合数据API

### 步骤2：配置API地址

修改 `h5/src/api/identity.js` 文件：

```javascript
// 将 BASE_URL 改为你的后端API地址
const BASE_URL = 'https://your-backend-api.com';
```

### 步骤3：开启验证开关

修改 `h5/src/pages/survey/basic.vue` 文件：

```javascript
data() {
  return {
    // 将 enableRealVerify 改为 true
    enableRealVerify: true,  // ← 这里改为 true
    formData: {
      // ...
    }
  }
}
```

完成！现在身份验证功能已启用。

## 开发建议

### 开发/测试阶段

建议保持 `enableRealVerify: false`，使用前端格式验证即可，原因：
- 节省API调用费用
- 开发调试更快速
- 不依赖后端服务

### 生产环境

建议启用 `enableRealVerify: true`，使用真实API验证，原因：
- 确保数据真实性
- 防止虚假信息
- 提升系统安全性

## 常见问题

### Q1: 为什么默认不启用？

A: 因为需要：
1. 后端API开发和部署
2. 第三方服务商账号注册
3. 费用预算审批

### Q2: 前端格式验证安全吗？

A: 
- ✅ 可以防止明显的格式错误
- ✅ 可以提取基本信息（年龄、性别）
- ❌ 无法验证姓名和身份证是否匹配
- ❌ 无法验证身份证是否真实存在

建议：在正式上线前启用真实API验证。

### Q3: 如何测试真实API验证？

A: 
1. 启用 `enableRealVerify: true`
2. 输入真实的姓名和身份证号
3. 查看是否能正确验证通过/失败

### Q4: API调用失败怎么办？

A: 系统已实现智能降级：
- 自动提示用户API服务不可用
- 询问用户是否继续（使用格式验证）
- 用户确认后可继续流程
