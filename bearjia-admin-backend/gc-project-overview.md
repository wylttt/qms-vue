## 业务流程图

### 完整业务流程
```
1. 基础数据准备
   ├─ 配置行政区划
   ├─ 设置采血点
   └─ 添加问卷调查员

2. 居民管理
   ├─ 录入居民信息
   ├─ 设计问卷
   └─ 居民填写问卷

3. 任务管理
   ├─ 创建采样任务
   ├─ 分配采血点
   └─ 指派调查员

4. 采血预约
   ├─ 创建预约记录
   ├─ 推送到第三方系统
   ├─ 接收采样状态回调
   └─ 更新预约状态

5. 筛查结果
   ├─ 录入筛查结果
   ├─ 自动识别高风险
   └─ 统计分析

6. 随访管理
   ├─ 高风险自动加入随访
   ├─ 分配随访任务
   ├─ 跟踪记录
   └─ 完成随访
```
