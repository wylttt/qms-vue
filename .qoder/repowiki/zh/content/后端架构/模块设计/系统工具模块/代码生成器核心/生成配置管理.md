## 核心组件分析

生成配置管理功能主要由前端Vue组件、后端控制器、服务层和实体类组成。前端通过`genCodeConfigUpdate.vue`组件提供用户界面，后端通过`GenController`处理请求，`GenTableServiceImpl`服务层实现业务逻辑，`GenTable`实体类定义数据结构。

```mermaid
graph TD
A[前端界面 genCodeConfigUpdate.vue] --> B[API接口 gen.js]
B --> C[后端控制器 GenController]
C --> D[服务层 GenTableServiceImpl]
D --> E[数据访问层 GenTableMapper]
D --> F[模板工具 VelocityUtils]
E --> G[数据库表 gen_table]
```

## 生成配置数据校验流程

生成配置的更新流程始于前端用户在`genCodeConfigUpdate.vue`组件中修改配置并点击确认。该操作触发`clickModalOk`方法，该方法首先验证表单数据，然后调用`updateGenTable` API将数据提交到后端。

```mermaid
sequenceDiagram
participant 前端 as 前端界面
participant API as API接口
participant 控制器 as GenController
participant 服务层 as GenTableServiceImpl
前端->>API : 调用updateGenTable(data)
API->>控制器 : PUT /tool/gen
控制器->>控制器 : @RequestBody GenTable genTable
控制器->>服务层 : validateEdit(genTable)
服务层->>服务层 : 验证配置数据
alt 验证通过
服务层-->>控制器 : 继续执行
控制器->>服务层 : updateGenTable(genTable)
服务层->>服务层 : 更新数据库
服务层-->>控制器 : 返回结果
控制器-->>API : 返回成功响应
API-->>前端 : 返回成功信息
else 验证失败
服务层-->>控制器 : 抛出ServiceException
控制器-->>API : 返回错误信息
API-->>前端 : 显示错误提示
end
```
